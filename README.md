# Pun Generator

The project that started it all, revived.

## From 2012 to now
**Then:** a console app that served puns to the pun-derful people in my life.
**Now:** the same idea with a shuffle bag (no repeats), topic filters, an experimental template generator, tests, and an accessible web easter egg on my portfolio. Try typing `pun` on https://traycn.github.io/.

## Run it
```bash
cd cli
dotnet run -- --topic code --count 3
```
